Does journaling add significant latency?
  w: 1        j: true adds +2.736 ms per write (+188.8%). Here the primary must flush its journal to disk before it replies.
  w: majority j: true adds -1.955 ms (-28.3%). With writeConcernMajorityJournalDefault = True, majority writes are already journaled, so j makes little difference.
  w: all      j: true adds +6.570 ms (+96.2%). The network wait for the slowest secondary dominates.
